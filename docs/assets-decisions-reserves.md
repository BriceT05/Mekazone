- Univers visuel unique : Automotive Premium — Modern E-commerce.

- Budgets de poids définis dans `docs/assets-strategy.md`.
- Hero mobile : dérogation acceptée le 23 novembre 2026 pour le recadrage 4:5 d'une photographie paysage (source Unsplash `wacb2ChxA4k`, Connor Botts).

## 2. Dérogations acceptées par l'utilisateur

- Hero mobile : composition verticale native non respectée ; recadrage 4:5 accepté.

- Catégories : six photographies produites et validées techniquement, non intégrées.
- B5 : validation visuelle humaine recommandée.
- B6 : auth-side sans alternative pleinement acceptable.
